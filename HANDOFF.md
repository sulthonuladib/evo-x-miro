## What the fix actually was

1. `device/xiaomi/miro/proprietary-files.txt`
   - removed the **195 source-built duplicate** blobs (the set the previous session had
     hand-removed from the generated `Android.bp`; a name-intersection approach that the
     build drove to convergence),
   - removed the 6 `frame*`/`fcmintf` libs (moved to common), `libprotobuf-cpp-full-21.12`,
     `boringssl_self_test64` and `vendor/etc/linker.config.pb` (all provided/generated by the
     build; the last caused a Makefile install cycle),
   - added `;DISABLE_DEPS` to 15 blobs whose AIDL dependency graph mixed interface versions
     (`graphicbuffersource-aidl-ndk`, camera/keymint/fingerprint/miracast blobs, …),
   - kept the 71 OS3 additions from the previous session.
2. `device/xiaomi/{miro,sm8750-common}/extract-files.py`
   - added `hardware/qcom-caf/wlan/qcwcn` to `namespace_imports`,
   - miro: `'libmdnssd': lib_fixup_remove` (Soong visibility),
   - common: `android.media.audio.common.types-V6-ndk` renamed to a `_xiaomi` variant
     (`FIX_SONAME` in the list) and the frozen sounddose HAL redirected to it.
3. `device/xiaomi/sm8750-common/proprietary-files.txt`
   - moved the display frame-manager chain here: `libframemaster` + `libframecapturemanager`
     (odm), `libframemasterintf` + `libfcmintf` + the two `-V1-ndk` (system_ext), and
     transitively `libbarrage`, `libnvticcontroller`,
     `vendor.novatek.hardware.visdisplaysrv-V1-ndk`,
   - `;DISABLE_DEPS` on `android.hardware.bluetooth.audio_sw` and
     `libaudio_aidl_conversion_common_ndk_xiaomi`.

`check_elf` triage is still deferred — the `DISABLE_DEPS` marks are pragmatic, not the final
dependency graph.
